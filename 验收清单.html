浏览器人工验收清单

> 使用方法：在浏览器打开 `index.html`，按顺序逐条点验。每条勾选 ☐→☑，发现异常记到文末"问题记录"。 > 预计耗时 5–8 分钟。首次加载字体约 8MB，稍等属正常。

一、门户页 index.html

#操作预期
---------------
1打开 index.html深色主题，两张卡片上方各有一块实时旋转的 3D 预览（左："3D"蓝色立体字；右：黄色小鸭子）
2等 3~5 秒观察文字卡"3D"立体字从方块/空白变为带倒角的立体字（字体 CDN 加载完成；若网络慢显示方块属降级设计）
3鼠标悬停卡片 / 点击边框变蓝、卡片上浮；点击正确跳转到 text3d.html / viewer.html

二、文字转 3D text3d.html

#操作预期
---------------
4首次进入深色界面，"GLM"三字母生成蓝色立体字（首次字体下载稍慢，之后秒开）
5输入「点 电 是」三个字的口/曰/日内部镂空（能看到背景），不再实心
6弯曲弧度滑杆拉到 180°文字变成半环（拱形），拉回 0 恢复
7点「试试示例 · 金属刻字效果」文字变「3D 打印」，金色金属质感，倒角高光
8材质预设四键切换原始(蓝)/金属(金)/霓虹(青发光)/石材(灰糙)即时切换
9「导出旋转动画」WebM 4s下载 .webm，播放为匀速旋转一圈，录完模型角度无变化
10「导出旋转动画」GIF 480px下载 .gif，循环播放无缝（首尾衔接无跳动）
11导出 GLB / STL / PNG 截图各得一个文件；PNG 为深色底 2 倍分辨率
12左上角房子图标返回门户页

三、3D 查看器 viewer.html

#操作预期
---------------
13点「🦆 示例 · 小鸭子」立即出现黄色小鸭（无需网络），自动旋转，脚下有软阴影
14点「🤖 示例 · 跳舞机器人」机器人出现并自动跳舞；动画面板可选片/暂停/0.5x~2x 倍速/拖进度条
15空格 / F / G / W / R 键空格=播放暂停，F=适配视图，G=网格开关，W=线框，R=复位
16灯光预设三档 + 曝光 + FOV摄影棚/柔光/暗室明显变光；曝光变亮暗；FOV 变广窄
17背景色 4 圆点 + 拾色器视口背景即时切换（默认深灰）
18拖入 duck.glb统计面板显示 6.9K 三角面/11 网格/3 材质；文件信息含体积
19双击鸭子身体相机焦点移到点击处（局部检查）
20转换面板选 STL出现橙色警告「将丢失全部材质与贴图」；点导出得到 .stl
21拖入不支持的文件（如 .txt）toast 提示「未找到模型主文件」，页面不崩溃
22左上角房子图标返回门户页

四、异常路径（可选，DevTools → Network → Offline）

#操作预期
---------------
23断网后刷新 text3d.html字体走 IndexedDB 缓存仍能生成；全新浏览器无缓存时提示「请检查网络」
24断网后刷新 viewer.html 打开示例示例按钮完全离线可用（程序化生成）
