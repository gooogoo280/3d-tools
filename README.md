# 3D 创作工具箱

> 文字转 3D · 模型查看与格式转换 —— 全部在浏览器本地运行的零安装 3D 工具站

在线体验：<https://gooogoo280.github.io/3d-tools/>

## 项目简介

3D 创作工具箱是一个纯前端 3D 工具站，包含两款工具：

1. **文字转 3D**（text3d.html）——输入中英文实时生成立体模型：挤出深度、倒角、弯曲弧度（戒指刻字）、金属霓虹材质，支持导入 SVG 图形转 3D，可导出 GLB / STL / OBJ（毫米级打印标定）直接 3D 打印，并能生成旋转动画（WebM/GIF）与网页嵌入代码。
2. **3D 模型查看与转换**（viewer.html）——拖入 GLB / glTF / STL / OBJ / FBX / PLY 即时预览：360° 旋转、骨骼动画播放（倍速/进度拖拽）、模型统计（顶点/三角面/材质/尺寸）、灯光与相机控制；一键转换导出 GLB / STL / OBJ / PLY / USDZ（iOS AR）。

**核心特性**：文件永不离开本机（全部解析、渲染、转换在浏览器本地完成）、零安装（发链接即用）、内置示例模型（小鸭子/跳舞机器人）即点即看。

## 技术架构

- **渲染引擎**：Three.js r160（CDN 三源容灾：jsdelivr → fastly 镜像 → unpkg 自动切换）
- **文字几何**：opentype.js 解析思源字体（锁定版本化 release Sans2.004/Serif2.003），真实轮廓挤出 + 孔洞嵌套挂载
- **性能**：Web Worker 几何生成（主线程零阻塞）、IndexedDB 字体缓存（二次访问秒开）
- **动画导出**：MediaRecorder（WebM）+ gif.js 无缝循环（GIF）
- **部署**：GitHub Pages + Actions 自动部署，单文件零构建，全站暗色专业风

## 目录结构

```

viewer.html    3D 模型查看与格式转换工具
duck.glb       示例模型（程序化生成）
og-image.png   社交分享图
```

## 使用方法

打开任一页面即可使用，无需注册与安装。文字工具输入文字实时生成；查看器拖入模型文件（支持文件夹整套拖入）即可预览与转换格式。
